# geoquizz
Quizz sur les pays en 10 questions en Python

Langage : Python.
Interface : terminal uniquement, sans interface graphique.
Jeu : quiz sur les pays du monde, avec questions et réponses aléatoires.
Données : un dataset CSV réel, chargé et nettoyé par le programme.
Fonctionnalités : menu, score, vies, progression, gestion des erreurs et sauvegarde du meilleur score.
Livrables : code, tests, README, dépôt Git et présentation de 10 minutes.


QUIZZZZ : GéoQuizz

Concept global : quiz sur les pays du monde, avec questions et réponses aléatoires. L’utilisateur commence le jeu avec 3 vies, chaque mauvaise réponse lui fait perdre une vie. La partie s’arrête à 10 questions ou quand le joueur n’a plus de vie.


Première page : Quand on arrive sur le jeu on affiche le nom du jeu, l’utilisateur démarre une nouvelle partie et rentre son nom.

Deuxième page : Le jeu se lance, l’utilisateur voit tout au long du jeu son nb de vie sur 3 ainsi que sa progression sur le jeu. La première question apparaît : l’utilisateur a le choix entre répondre directement sans voir de propositions ou il peut voir 4 réponses proposées ou duo cash, son nb de points gagnés varie en fonction de ça.
Ainsi de suite pour les autres pages jusqu’à la fin des 10 questions.
Si l’utilisateur perd ses 3 vies avant, il a le choix de quitter le jeu ou de recommencer une nouvelle partie.

Dernière page : fin de partie avec le nb de vie restants et nb de points. (Afficher où est ce qu’il se trouve dans le classement ?). Possibilité de nouvelle partie ou quitter le jeu.

Thèmes de question : 
capitales
régions
langues
monnaies
